# Результаты технического аудита

Область: рабочая копия server, Prisma schema/migrations, тесты, локальный Docker Compose/PostgreSQL metadata и безопасная конфигурационная проверка. Строки пользовательских таблиц и секреты не читались. Это не penetration test и не аудит ОС/внешнего proxy.

## Исправлено в этой рабочей копии

- Удалены пароль PostgreSQL и URL подключения с fallback credentials из Compose, шаблона окружения и Prisma; теперь нужны явные значения.
- Dependency audit: уязвимости в Zod и транзитивных пакетах устранены совместимыми обновлениями lockfile; dev цепочка ESLint использует `minimatch@11.0.4` override.
- AI runtime больше не наследует весь `process.env`: DB URL, session secret, OAuth secrets и proxy не передаются дочернему Python; передаются runtime-настройки и ограниченный список системных переменных.
- Свободный stderr Python runtime больше не попадает в application logs.
- Legacy `app.py` при standalone запуске слушает только `127.0.0.1`; исключения и текст пользовательского запроса не пишутся в stdout.
- Добавлено аутентифицированное удаление своей учётной записи с существующими каскадами и HTTP тестом.
- Добавлены зашифрованный backup script и документация; автоматическое расписание не включено.

## Открытые значимые риски

1. **Высокий:** app DB role имеет SUPERUSER, CREATEDB, CREATEROLE. Не менялось, чтобы не лишить работающий сервис необходимых прав без staging, backup и rollback.
2. Регион и локализация, TLS внешнего proxy, firewall/public exposure и контроллеры доступа host не проверены.
3. Сроки хранения пользователей и сообщений, договоры с обработчиками и legal basis не подтверждены.
4. Не задана ротация application/container logs и не было подтверждённого существующего backup до внедрения скрипта.
5. Dev dependency audit предлагал принудительный ESLint downgrade; вместо этого добавлен и установлен `minimatch` override. Полный и production audit, lint и тесты прошли после обновления.
6. Runtime/модель находятся за пределами проекта; код, dependency supply chain, доступы и retrieval traffic не проверялись.
7. В текущей рабочей копии AI backlog ограничен `AI_MAX_PENDING_REQUESTS`; rate limiter и очередь in-memory не разделяют состояния между инстансами и сбрасываются при рестарте.

## Последующее обновление

HTTP-логи теперь используют route template и случайный request ID вместо реального пути. Self-delete очищает session cookie и протестирован на изолированном API mock. Backup script не удаляет старые архивы автоматически и проверяет, что passphrase не находится в каталоге архивов. Эти изменения ещё не подтверждены как развёрнутые на сервере.

## Конфиденциальность

`.env` с режимом `0600`, не отслеживается Git и не выведен. Согласно `git ls-files`, файл не является текущим tracked-файлом; поиск истории по пути не выявил commits. Это не доказывает отсутствие похожих credential в иных путях или прошлых удалённых копиях. Ротация не выполнялась.
