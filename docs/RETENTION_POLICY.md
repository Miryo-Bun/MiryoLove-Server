# Хранение и удаление

Это инвентаризация текущего поведения, а не утверждённый оператором срок хранения. Сроки для целей обработки, законные основания и исключения определяются владельцем с юристом; не подменять их техническими defaults.

| Данные                   | Текущая техническая политика                                                                                                  | Требуемое решение                                                                                                                                    |
| ------------------------ | ----------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| Аккаунт, профиль, OAuth  | До user-initiated deletion                                                                                                    | Утвердить основание и срок после завершения отношений.                                                                                               |
| Пароль hash              | До удаления аккаунта                                                                                                          | Утвердить срок и порядок смены/восстановления.                                                                                                       |
| Сессия                   | По умолчанию до 30 дней; проверяется при использовании; истёкшие удаляются лениво                                             | Установить короткий достаточный срок и регулярно очищать протухшие строки только после проверки процесса.                                            |
| Чаты/сообщения/источники | Без автоматического срока; каскадное удаление при удалении чата/аккаунта                                                      | Утвердить срок для пользовательского контента и legal hold исключения.                                                                               |
| HTTP/application logs    | Приложение выдаёт структурированные события; ротация/retention не настроены в Compose                                         | Установить срок, лимиты, access-control и правила инцидентного hold.                                                                                 |
| Database backups         | Скрипт показывает ориентиры 14 daily / 8 weekly / 12 monthly; автоматически не удаляет копии. Расписание и срок не утверждены | Назначить владельца, off-host хранилище и процедуру restore. Удалять только после утверждения срока хранения и проверки сохранности требуемых копий. |
| Внешние провайдеры       | Не определяется сервером                                                                                                      | Уточнить сроки и договоры у каждого обработчика.                                                                                                     |

Подтверждённое удаление аккаунта каскадирует в основной БД, но не включает уже созданные backup и логи. Не запускать backup retention/purge как замену утверждённой политике.

## Техническое обновление

`scripts/backup.sh` проверяет расшифровку и контрольный список архива до публикации, но скрипт не является политикой хранения. Копии не удаляются при создании следующего backup. Удаление данных из архивов по запросу пользователя и предельный срок хранения архивов не определены; это остаётся решением владельца и юриста.
