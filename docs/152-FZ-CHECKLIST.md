# Технический чеклист по 152-ФЗ

Не является юридическим заключением или подтверждением соответствия. Применимость зависит от фактического оператора, субъектов и целей.

| Проверка                                                       | Техническое состояние                                                                                                   | Следующий шаг                                                                                                                            |
| -------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| Определён оператор и цели (ст. 3, 5)                           | Не подтверждено кодом                                                                                                   | Владелец фиксирует оператора, цели, категории субъектов и операций.                                                                      |
| Правовое основание (ст. 6)                                     | Не кодируется и не подтверждено                                                                                         | Юрист сопоставляет отдельные цели и основания; не считать вход/регистрацию универсальным согласием.                                      |
| Конфиденциальность и организационные обязанности (ст. 7, 18.1) | Частично: технические контроли есть, организационные документы/ответственные не подтверждены                            | Утвердить политику, внутренние регламенты, доступы, обучение и контроль.                                                                 |
| Локализация (ст. 18(5))                                        | География БД, резервов, runtime и обработчиков не подтверждена                                                          | Проверить фактическое место записи/систематизации/накопления/хранения/уточнения/извлечения и исключения закона, включая amendment 23-ФЗ. |
| Уведомление Роскомнадзора (ст. 22)                             | Не проверено                                                                                                            | Владелец/юрист проверяет применимость обязанности и исключения до обработки.                                                             |
| Безопасность (ст. 19)                                          | Частично реализованы auth, validation, access controls и safe errors; DB role избыточна, TLS PostgreSQL не включён      | Провести оценку угроз/уровня; применить только после согласования least-privilege/TLS планы, backup/DR и инфраструктурные меры.          |
| Запросы/удаление                                               | Profile read/update и self-delete с отзывом сессии и очисткой cookie; export/workflow отсутствуют                       | Утвердить процесс подтверждения субъекта, сроки исполнения, исключения и копии.                                                          |
| Инциденты (ст. 21(3.1))                                        | Автоматическое уведомление не реализовано и не должно отправляться автоматически                                        | Подготовить контакты и процесс оценки 24-часового/72-часового сроков.                                                                    |
| Обработчики/трансграничная передача                            | Google, Yandex и wiki endpoints предусмотрены; договоры/локации не проверены                                            | Инвентаризировать получателей, поручения, трансграничность и соответствующие правовые условия.                                           |
| Минимизация и сроки                                            | Основная схема ограничена профилем/сессиями/чатом, но чаты/логи/backup бессрочны; backup-скрипт не удаляет старые копии | Утвердить конкретные цели, сроки и правила удаления/backup.                                                                              |

Техническое обновление в рабочей копии: HTTP middleware пишет route template и случайный request ID вместо path с chat UUID; AI очередь ограничена настройкой. Тесты не устанавливают срок хранения внешних stdout logs и не проверяют межинстансовый rate limit.

## Правовые источники для проверки

- Федеральный закон от 27.07.2006 №152-ФЗ, в частности статьи 3, 5–7, 18(5), 18.1, 19, 21(3.1), 22: [официальный правовой портал](https://pravo.gov.ru/proxy/ips/?docbody=&nd=102108261).
- Информация/сервис уведомления операторов: [Роскомнадзор](https://pd.rkn.gov.ru/operators-registry/notification/).
- Сообщение об инциденте: [Роскомнадзор](https://pd.rkn.gov.ru/incidents).

В ходе подготовки документа страницы официальных доменов были недоступны из среды проверки. Перед утверждением сверить действующую редакцию и применимые подзаконные акты на официальном портале; приведённые ссылки не заменяют юридическую проверку.
