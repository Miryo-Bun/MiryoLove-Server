# Архитектура MiryoLove Server

## Состояние и границы

Документ описывает состояние кода в этой рабочей копии. Он не подтверждает настройки DNS, reverse proxy, firewall, хостинга или других репозиториев.

```text
Браузер / MiryoLove AI Web
    └── REST + cookie → Express 5 / TypeScript (src/)
                           ├── Prisma 7 → PostgreSQL 17 (Compose)
                           └── ограниченный env → Python AI Runtime (внешний путь)
                                                    └── MiryoWiki / Wikipedia (при поиске)
Google / Yandex OAuth ←→ OAuth service → PostgreSQL
```

`src/server.ts` создаёт HTTP-сервер, сервисы, проверку PostgreSQL и обработчики остановки. `src/app.ts` связывает Helmet, журналирование, CORS/Origin, JSON body limit, health checks, маршруты, development-only Swagger и единый обработчик ошибок. API состоит из Express routes, controllers, Zod schemas и сервисов с контрактами.

`app.py` — отдельный старый FastAPI endpoint. Поиск workspace не обнаружил вызывающих его проектов/скриптов; frontend использует `/api/ai/chat`. Он не подключён к `src/server.ts` или Compose; при прямом запуске привязывается к loopback. Возможный ручной/внешний запуск не проверен. Не выставлять его отдельно в сеть: самостоятельная legacy-реализация не имеет проверки сессии MiryoLove. Удалять только после подтверждения владельцем, что внешних потребителей нет.

### План вывода legacy endpoint (не выполнен)

1. Владелец проверяет процессы systemd/cron/ASGI, reverse proxy, firewall, мониторинг, внешние инструкции и журналы обращений на хостах, доступных оператору. Никакие сервисы не останавливаются для этой проверки.
2. Если внешний потребитель обнаружен, перенести его на аутентифицированный Express `/api/ai/chat` либо до отдельного решения реализовать для legacy endpoint независимые auth, rate/size/time limits и сетевой egress allowlist. Не публиковать endpoint в текущем виде.
3. Если потребителей нет, владелец назначает период предупреждения/наблюдения; затем в отдельном изменении удалить `app.py` и его archive-list reference из `scripts/backup.sh`, удалить только неиспользуемые зависимости/документацию и проверить Python/Compose/frontend references.
4. Перед deployment проверить тесты актуального Express AI endpoint, отсутствие старого маршрута в package/service definitions и rollback через предыдущий versioned release. Удаление файла или остановка возможного внешнего процесса здесь не выполнялись.

## Компоненты, данные и риски

| Компонент                   | Назначение и технология                                            | Данные/связи                                                                   | Риски и состояние                                                                                                                                |
| --------------------------- | ------------------------------------------------------------------ | ------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| HTTP API                    | Express 5, TypeScript, Zod                                         | JSON профилей, учётных записей, чатов и сообщений                              | Маршруты профиля и чатов требуют серверную сессию; владельцем чата проверяется каждый доступ.                                                    |
| Auth/OAuth                  | Argon2id, случайные сессии, HMAC, HTTP-only cookies, Google/Yandex | email, имя, hash пароля, OAuth ID, hash сессии, сроки                          | Пароли и токены не возвращаются клиенту; восстановление пароля и связывание OAuth не реализованы.                                                |
| PostgreSQL                  | PostgreSQL 17 в локальном Compose volume; Prisma 7                 | users, oauth_accounts, sessions, chats, messages, миграции                     | В текущей конфигурации приложение подключено ролью PostgreSQL SUPERUSER. TLS не используется на проверенном локальном соединении.                |
| AI boundary                 | Локальный child process, JSON-lines protocol                       | Текущий текст и до настроенного количества предыдущих user/assistant сообщений | Child получает только whitelist переменных окружения; stderr не записывается как текст. Очередь ограничена `AI_MAX_PENDING_REQUESTS` на процесс. |
| Retrieval / OAuth providers | HTTP(S), внешние identity/wiki сервисы                             | OAuth-код и профиль; запросы для получения справочного контекста               | Фактические договоры обработки, регион и политика хранения у поставщиков требуют проверки владельцем.                                            |
| Логи                        | Pino, HTTP middleware                                              | Метод, шаблон маршрута, status, latency, request ID                            | Фактический path, body, query, cookie, IP и текст сообщений middleware не пишет. Настройки хранения/ротации контейнерных логов не заданы.        |
| Docker Compose              | `postgres:17-alpine`, named volume, localhost port binding         | Переменные окружения PostgreSQL                                                | В Compose только база; API и модель запускаются отдельно. Дефолтный пароль удалён, теперь его нужно явно задать.                                 |

## Маршруты

Актуальные методы и требования авторизации перечислены в [README.md](../README.md) и OpenAPI (`src/docs/openapi.ts`). Основные группы: `/api/auth`, `/api/users/me`, `/api/chats`, `/api/ai/chat`, `/health`.

## Проверенное окружение

На момент обследования: Node.js 26.13.0, npm 12.2.1, Python 3.14.9, Compose 5.6.1, PostgreSQL 17.11, Prisma 7.10.0. Это версии доступных локальных инструментов и сервера БД, не универсальная матрица поддержки. Package engines требует Node.js >=20.19.

Локальный `.env` имеет режим `0600`, не индексируется Git и его содержимое не включено в документацию. Размер данных, регион размещения хоста, публичная топология, модель и зависимости Python runtime отдельно у владельца не подтверждены.
