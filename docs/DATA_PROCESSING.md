# Карта обработки персональных данных

## Статус

Это техническая инвентаризация кода, не юридическое заключение и не утверждение о соблюдении 152-ФЗ. Фактический оператор, его цели, субъекты, договоры, география инфраструктуры и правовые основания должен подтвердить владелец.

## Поток

```text
Пользователь → HTTPS (внешний termination не проверен) → Express
  ├─ регистрация / профиль / сессии → PostgreSQL
  ├─ чаты и сообщения → PostgreSQL → локальный Python runtime
  │                                        └─ при поиске: wiki/Wikipedia API
  └─ OAuth redirect ↔ Google / Yandex → email/имя/avatar → PostgreSQL
PostgreSQL → локальный Docker volume
Резервная копия → локальный зашифрованный архив (после настройки BACKUPS.md)
```

## Сроки и жизненный цикл

| Категория                        | Где хранится                                               | Цель по коду                                                     | Срок хранения                                                           | Удаление                                                                                  |
| -------------------------------- | ---------------------------------------------------------- | ---------------------------------------------------------------- | ----------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| Аккаунты, профиль, password hash | `users` в PostgreSQL                                       | Регистрация, вход, профиль                                       | Не установлен; записи сохраняются до self-delete                        | Аутентифицированный `DELETE /api/users/me`; пароль хранится только как Argon2id hash      |
| OAuth-данные                     | `oauth_accounts`; email/name/avatar из provider в `users`  | Вход через Google/Yandex                                         | Не установлен; до удаления аккаунта                                     | Удаляются FK cascade при self-delete                                                      |
| Сессии                           | `sessions` в PostgreSQL; opaque token в браузерной cookie  | Аутентификация                                                   | До 30 дней по умолчанию; регулярная очистка истёкших строк не настроена | Logout/self-delete удаляет серверные сессии; self-delete также очищает cookie в ответе    |
| Чаты                             | `chats` в PostgreSQL                                       | История пользователя                                             | Не установлен                                                           | Удаление чата или self-delete с каскадом                                                  |
| Сообщения и источники            | `messages` в PostgreSQL; временно в HTTP/AI process memory | История и генерация ответа                                       | Не установлен                                                           | Каскад при удалении чата/account; внешнее удаление данных retrieval-провайдера неизвестно |
| Технические журналы              | stdout; дальнейшая система хранения не установлена         | Диагностика method, route template, status, duration, request ID | Не установлен                                                           | Приложение не управляет внешней ротацией/удалением                                        |
| Резервные копии                  | Локальные зашифрованные архивы                             | Восстановление PostgreSQL/исходников                             | Не установлен; архивы не удаляются автоматически                        | Нет автоматического удаления; срок и off-host процесс не утверждены                       |

Удаление аккаунта не удаляет ранее созданные резервные копии и журналы. Экспорт данных пользователя и workflow для неаутентифицированных запросов/подтверждения личности не реализованы. Не заявлять, что self-delete эквивалентен полному исполнению всех запросов субъекта.

## Действия пользователя

Пользователь может прочитать и обновить свой профиль. `DELETE /api/users/me` удаляет строку пользователя, очищает cookie в ответе и запускает каскады PostgreSQL для OAuth связей, сессий, чатов и сообщений. API tests проверяют поведение на mock services, а отдельная ранее проверенная копия БД подтверждает schema cascade; endpoint не тестировался удалением данных в production. Он не удаляет копии из backup и внешние журналы. Запрос другого пользователя к чужому чату возвращает 404; тесты проверяют блокировку чтения/изменения/удаления.
